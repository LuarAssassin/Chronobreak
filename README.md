# Chronobreak

用 Rust 构建我们自己的 GUI 框架。

采用保留 UI 树、自绘渲染与响应式状态更新，逐步打通「界面描述 → 状态更新 → 布局与文字排版 → 绘制 → 窗口与交互」的闭环。复用成熟底层库，把精力投入框架核心。

## 当前状态

项目基础与参考资料已经建立；第一个实现目标是可调整窗口大小、显示中文、支持点击计数的信息卡片。功能在独立分支开发，通过审查与验证后合入 `main`。
