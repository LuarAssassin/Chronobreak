# 初始架构方向

Chronobreak 是用 Rust 构建的保留模式、自绘 GUI 框架，不是对现有完整 GUI 框架的外层封装。

## 第一版取舍

- 界面表达：优先使用原生 Rust builder；在真实使用反馈出现前，不引入自定义语法或过程宏。
- 状态更新：采用 Signal 思路，明确依赖订阅、批量更新和节点销毁时的清理；首版聚焦 UI 线程，不提前泛化为跨线程响应式系统。
- 布局：复用 `taffy` 的 Flexbox；文字测量必须接入真实排版结果，不以字符数乘字号代替。
- 文字：优先探索 `cosmic-text` 与 `glyphon` 的组合，支持中文与字体回退。
- 绘制：从 UI 树生成独立于 GPU 的显示列表，由 `wgpu` 执行；处理绘制顺序与裁剪。
- 平台：使用 `winit` 处理窗口、事件循环、尺寸与 DPI 变化；区分逻辑坐标与物理像素，空闲时不持续重绘。

具体 crate 版本由实现时核对兼容性后锁定。成熟底层库负责标准与平台细节；项目负责组件模型、树的生命周期、更新传播和交互语义。

## 第一个可运行目标

一个由框架自身渲染的信息卡片，包含标题、中文说明和计数按钮。点击按钮更新数字；改变窗口大小后文字正确换行，布局随之更新；交互经过事件命中、回调、状态变化、布局和绘制的完整链路。

验证分开记录：不依赖窗口的状态／布局／命中测试，以及真正运行渲染路径后的画面与交互验证。显示环境缺失时明确指出，不能把编译通过当作图形验证通过。

首版不扩展为完整控件库，不加入过程宏、动画系统、复杂文本编辑、插件系统或跨平台发布流水线。输入法、无障碍等保留为后续明确功能，不虚称首版已支持。

## 当前实现边界

- `src/ui.rs`：builder 挂载一次，节点与 taffy ID 保留；文本 buffer 同时用于布局测量和 glyphon 绘制。宽度约束交给 cosmic-text 的 `WordOrGlyph` 排版，最终布局宽度再次同步至 buffer。
- `src/signal.rs`：UI 线程 `Rc<RefCell<_>>` 状态；更新在释放借用后通知订阅，值未变化不通知。不承诺跨线程或可重入写入的事务语义。节点持有 RAII 订阅，整棵树销毁时解绑，订阅闭包仅弱引用待更新队列，不延长树寿命。
- 多次更新按节点合并为最后的文本，`Scene::sync` 只修改订阅节点并标记 taffy 脏路径；不重建 UI 树。不做通用依赖自动追踪、树 diff、动态子树增删或跨 Signal 事务；未来增删节点时必须先释放对应订阅并清除待处理项。
- `src/render.rs`：独立显示列表按父背景、父文本、子节点顺序提交 GPU，矩形 scissor 和文本 bounds 使用继承裁剪；每个文本节点单独保留 renderer，避免把所有文本错误地提升到背景之上。首版每次脏事件全帧重绘，不宣称 GPU 局部重绘。
- `src/main.rs`：布局和命中使用逻辑像素；窗口尺寸、指针输入、surface、scissor 使用物理像素，通过窗口 scale factor 转换。零尺寸不渲染，恢复与 DPI 变化重新布局；失效 surface 重配，超时跳过本帧。空闲使用 `ControlFlow::Wait`，点击或窗口事件请求重绘。外部状态写入需要调用方安排同步与重绘，尚无跨线程唤醒器。
